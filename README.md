# 项目导航

| 想做什么 | 可以从这里开始 |
|---|---|
| 把图案变成装饰 PCB | [Image2PCB Art 在线工具](https://xiaohai-uid.github.io/image2pcb-art/)在浏览器内预览材料层并导出 Gerber。 |
| 看 AutoCAD 实际画出的机械图 | [AutoCAD Live MCP 示例图](https://github.com/xiaohai-uid/CAD-AutoCAD-Platform/blob/master/docs/img/reducer_assembly_A3.jpg)展示一张 A3 减速器装配图。 |
| 快速查看线材测试批次 | [质量热力图演示](https://xiaohai-uid.github.io/wire-cable-rd-manager/)可从产品和测试项下钻到批次记录。 |
| 在 Windows 上写长篇小说 | [灵笔发行页](https://github.com/xiaohai-uid/lingbi/releases)提供安装版和便携版。 |
| 用代码复现长篇小说的章节工作流 | [storyrepo](https://github.com/xiaohai-uid/storyrepo)提供 Python 章节合同、机检和回炉演示。 |
